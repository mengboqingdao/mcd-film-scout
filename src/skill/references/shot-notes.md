# 镜头语言速查

按活动类型查。构图三选一，光线二选一，器材固定。

## 派对 / 生日 / 亲子

**构图**
- 中心人物 + 环状视线：把寿星或主角放在中心，其他人视线向内围一圈
- 低机位贴桌面：气球、吊饰从画面上沿入画，纵深拉起来
- 俯拍桌面全景：把道具排成对角线，画面立刻有秩序

**光线**
- 室内顶光为主，注意顶光会在脸上留硬阴影，让人物侧 45° 避开
- 蛋糕切开的瞬间抓表情，闪光灯只在补眼神光时用

**道具**：蜡烛（点亮的瞬间）、彩带拉出的线、纸帽的边缘反光

## 品鉴 / 新品 / 美食

**构图**
- 45° 俯角主图：餐盘放三分线交点，前景留虚化
- 手部动作特写：拿起、掰开、倒酱——比静态摆盘有生气
- 贴桌面平视：利用桌面反光做倒影，增加层次

**光线**
- 侧逆光勾食物轮廓，背景压暗一档
- 用白盘或白杯做参照，白平衡才不会跑偏

**道具**：汉堡横截面（层次最出）、薯条盒金属反光（前景）、蛋挞焦斑（微距）、咖啡拉花（俯拍几何）、可乐杯壁冷凝水珠（特写显新鲜）

## 夜场 / 节庆 / 灯节

**构图**
- 店外灯箱与霓虹做背景光，人物做剪影
- 长曝光 1/15 秒以上，来往人流拉成连续光带
- 靠窗向外拍，玻璃反射做双重画面

**光线**
- 以店内暖光为主光，关闭自动白平衡保留暖调
- 用小反光板或手机手电给主体补眼神光

**器材**：脚架必备；镜头遮光布（防路灯鬼影）；关掉机内防抖后用 1/15 更稳

## 通用

**器材**（任何场景都适用）
- 机身：任意可手动曝光的相机或手机专业模式
- 焦段：35–50mm 拍环境与人物；85–200mm 拍细节与虚化
- 快门：环境 1/60 秒以上保持稳定；想拉光带 1/15 秒并上脚架
- 白平衡：固定 4000K 左右，现场拍摄避免自动跳色
- 存储：连续拍摄前清一次卡

**抓拍原则**
- 等动作发生的那一刹那按快门，别摆
- 连拍优于单拍，序列里总有一张能用
- 拍完立刻回看构图，下一张就改
